# Predict Station

A monorepo containing:
- **CLI** (root) - Published on NPM as `predict-station`
- **frontend/** - Next.js web application

## CLI Usage

```bash
npx predict-station init
npx predict-station start
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Development

This is the initial setup. The Electron app migration from the original predict-station will be placed in the `frontend` folder.
